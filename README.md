# Profile Card

A responsive, mobile-first profile card built with pure HTML, CSS and JavaScript.

## Features

- Mobile-first responsive design (phone, tablet, desktop)
- Landscape mode support for phones
- Dark / Light mode toggle
- Theme is saved in `localStorage`
- Touch-friendly buttons and links (44px minimum)
- Safe-area support for iPhone notch
- Respects `prefers-reduced-motion`

## Tech Stack

- HTML5
- CSS3 (Flexbox, Grid, CSS Variables, `clamp()`, media queries)
- Vanilla JavaScript

## Project Structure

```
profile-card/
├── image/
│   └── profile.jpg
├── index.html
├── style.css
├── script.js
└── README.md
```

## Run Locally

```bash
git clone https://github.com/Ozodbek-27/profile-card.git
cd profile-card
```

Then open `index.html` in your browser.
